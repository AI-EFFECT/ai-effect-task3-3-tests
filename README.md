# AI-EFFECT Task 3.3 Test Suites

This repository contains repeatable test suites for the AI-EFFECT Task 3.3 use cases.

Each node folder is self-contained. It contains its own test scripts, setup guidance, expected results, and release notes.

## Important

- This repository contains test automation only. It does not contain the use-case source code.
- Each node suite identifies the repository baseline it expects.
- Do not commit API keys, local settings files, Docker credentials, evidence folders, or participant data.
- A failed test may document a known product defect. Read the node-specific release notes before treating a result as a new issue.
